# SUC-7: Publication Roadmap — Nature Methods Submission

**Linear issue:** [SUC-7](https://linear.app/suchen/issue/SUC-7/publication-roadmap-nature-methods-submission)
**Status:** Backlog
**Priority:** High

## Goal

Track the gap between current imputeVAE results and the bar required for a Nature Methods publication. Define experiments and milestones needed to close that gap.

## Key Requirements (Nature Methods)

1. Clear technical novelty
2. Rigorous benchmarking against existing approaches
3. Biological insight beyond metrics
4. Demonstrated generalizability
