**Linear issue:** [SUC-10](https://linear.app/suchen/issue/SUC-10/biological-validation-downstream-use-case-demonstration)

## Problem

All current evaluation is statistical (classification, DE overlap, correlation). We have no concrete demonstration of a biological application where imputed profiles enable something that raw nuclei cannot.

## Candidate Use Cases

1. Cytoplasmic RNA recovery (Malat1, Slc17a7, Gad1/2)
2. Cross-modality atlas integration
3. Cell-type-specific eQTL re-analysis
4. Regulatory network inference improvement
